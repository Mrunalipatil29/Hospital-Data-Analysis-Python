#  Hospital Data Analysis

## Project Overview

This project analyzes hospital data to identify important insights related to hospital performance, patient volume, departments, doctors, medical expenses, admissions, and hospital stay duration.

The analysis was performed using Python and popular data analysis libraries such as Pandas, NumPy, Matplotlib, and Seaborn.


##  Project Objectives

The main objectives of this project are to:

* Analyze hospital and department performance.
* Identify hospitals with the highest patient volume.
* Analyze patient distribution across different locations.
* Analyze department-wise patient counts.
* Analyze doctor and patient workload.
* Analyze medical expenses across hospitals and departments.
* Calculate the average length of hospital stay.
* Calculate patients per doctor.
* Calculate medical expenses per patient.
* Identify trends in patient admissions over time.
* Generate meaningful business insights using data visualization.
